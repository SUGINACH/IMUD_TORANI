# Tora Book Typesetter — "Orange"

מערכת עימוד תורנית מקצועית לדפי A4 (עברית, ימין-לשמאל): שני טורים, הערות צד והערות שוליים, כותרות בכל הרמות,
שערים, תוכן עניינים, עיטורים והדפסה. אתר סטטי — **אין תהליך build**.

זהו **הענף המאוחד** של פרויקט `IMUD_TORANI` (`main`): הוא נבנה מחמשת הענפים שפותחו במקביל (V20.1–V20.5) ומקו V21,
עם בדיקות אוטומטיות שמונעות איבוד התקדמות. הענפים V20.1–V20.5 נשארים כחומר מקור. מצב האיחוד: [`docs/UNIFICATION_PLAN.md`](docs/UNIFICATION_PLAN.md).

## הרצה

```bash
tools/import-from-old-repo.sh        # פעם אחת: מייבא את תיקיית fonts/ (כ-264MB) מהריפו הישן - חובה לעימוד נכון
python -m http.server 8000           # או כל שרת סטטי אחר / GitHub Pages
# ואז לפתוח http://localhost:8000/
```

(פתיחה ישירה של `index.html` כקובץ לא מספיקה: האפליקציה טוענת קובצי JSON בבקשות fetch.)

## מבנה

| נתיב | תפקיד |
|---|---|
| `index.html`, `style.css`, `app.js` | ממשק: הדבקת טקסט, לוח הגדרות, תצוגה מקדימה, ייצוא |
| `typesetter.js` | מנוע העימוד (טורים, איזון, חיתוך פסקאות, הערות, כותרות) |
| `decorations.js` | שערים, עיטורים, כותרות עליונות, קווי הפרדה |
| `settings-manager.js`, `default_settings.json`, `setting_sets/` | הגדרות ברירת מחדל, שמירה, ייבוא/ייצוא, סגנונות |
| `*.json` (shaar_*, ornaments_*, section_dividers, note_rules ...) | נתוני שערים, עיטורים, קווי הפרדה, כללי הערות |
| `fonts-*.css/json`, `fonts/` | הגדרות וקובצי גופנים (התיקייה מיובאת בנפרד) |
| `tests/` | בדיקות קבלה: גיאומטריית עימוד (21 תרחישים) + בדיקות פיצ'רים |
| `docs/` | תוכנית איחוד, מפת פיצ'רים, מקורות, ניתוח הענפים, מאגר ידע (תיעוד טכני, יומני כשלונות, שיחות) |
| `archive/` | קוד של הגרסאות האחרות (קו V21, מנועי V20.x, Knuth-Plass של V18) — חומר להעברה, **לא נטען** באפליקציה |
| `presets/` | הגדרות אמיתיות של הספר "מקום בינה" מ-V20.5 |
| `tools/` | סקריפטים: ייבוא נכסים מהריפו הישן, מחולל סקירת הגדרות |
| `claude_v20/`, `zai_v21/`, `chatgpt_v23/` | תיעוד שלושת קווי הפיתוח במקביל (Claude / z.ai GLM / ChatGPT): תמלילים, תיעוד טכני, קטלוגי בעיות |
| `wiki/`, `shared/`, `source_code/`, `text_files_for_typesetter_tests/` | ויקי, חומרים משותפים, צילום קוד טקסטואלי וקבצי טקסט לבדיקות |

## בדיקות

```bash
npm install && npx playwright install chromium     # פעם אחת
npm run test:layout:quick      # ~1 דקה
npm run test:layout            # ~4 דקות, 38 תרחישים (נכשל אם סוג חריגה כלשהו גדל מול baseline)
npm run test:features          # בדיקות פיצ'רים
node tests/audit/settings-effect.js --fast --shard=0/3   # ביקורת: איזו הגדרה משפיעה בפועל (3 חלקים)
```

**כל שינוי חייב לעבור את הבדיקות לפני שהוא מתקבל** — ראו [`docs/AI_WORKFLOW.md`](docs/AI_WORKFLOW.md).
