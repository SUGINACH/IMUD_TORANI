# פריסטים

## `makom-bina-v20.5/`
ההגדרות האמיתיות של הספר "מקום בינה" כפי שנשמרו בענף V20.5: `default_settings.json` + שלושת ה-`setting_sets`.

**שימו לב:** שמות הגופנים בהם הם בעברית (למשל "ליבורנה רגיל", "פרנק רוהל ליברה רגיל") — כנראה גופני מערכת המותקנים אצל המשתמש —
בעוד שבוררי הגופנים בבסיס משתמשים בשמות אנגליים (`'Livorna'`, `'Frank Ruhl Libre'` ...). לכן ייבוא ישיר מציב גופני fallback (`serif`).
לפני שימוש יש להמיר את שמות הגופנים או לוודא שהגופנים העבריים קיימים במחשב. (הערך נשמר כאן כדי לא לאבד את בחירות העיצוב — צבעים, גדלים, סגנונות — ולא כברירת מחדל.)
